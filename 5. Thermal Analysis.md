# According to Solidworks design the following assumptions and calculations are performed 

## The process is Serverbox - Thermal tube - Radiator - Space 

Data:- 

1. Server box = 200 * 150 * 150 mm
2. Tube = $$\phi$$ 20 * 300 mm
3. Radiator = 300 * 400 * 2 mm
4. Radiator Emissivity = 0.92
5. Server heat generation = 150 W
6. Aluminum Thermal conductivity = 273 W/m.k
7. Aluminum Density = 2700 $$kg/m^2$$
8. Specific heat = 900 J/kg.k
9. Space Temperature = 3k
10. Stefan-Boltzman constant = $$5.67*10^-8 W/m^2.k^4$$
11. Radiaton = Only one side of plate

### 1. Converting all dimensions to SI units

1. Server box = 0.2m, 0.15m, 0.15m
   Therefore Volume of server box is = $$0.2 * 0.15 * 0.15 = 0.0045m^3$$

2. Thermal tube = D = 0.02m, L = 0.3m
3. Radiator = 0.3m, 0.4m, 0.002m

### 2. Server heat generation

Qgen = 150W

### 3. Radiator surface area

A = (0.3 * 0.4) * 4...............(We are using 4 radiator according to refrence)

A = 0.48 $$m^2$$

### 4. Radiator volume 

Vrad = (0.3 * 0.4 * 0.002) * 4 = 0.00096 $$m^3$$

### 5. Radiator mass

$$\rho = 2700kg/m^3$$

$$m=\rho * v$$ 

m = 2700 * 0.00096 = 2.592kg

### 6. Thermal radiation calculation

$$Qrad = $$\epsilon \sigma A(Trad^4 - Tspace^4)$$

where,

$$\epsilon$$ = 0.92 , $$\sigma = 5.67*10^-8 W/m^2k^4$$ , $$A = 0.48m^2$$ , Tspace = 3k

### 7. Assuming radiator temperature 350k (https://www.nss.org/settlement/nasa/spaceresvol2/thermalmanagement.html)

Trad = 350k

$$Qrad = 0.92 * 5.67*10^-8 * 0.48 *(350^4 - 3^4)$$

Qrad = 375W

#### Result =  Qrad > Qgen

## The report generated by SOLIDWORKS

#### Conclusion = The radiator does complete rejection from server box 

An initial radiator design was evaluated by assuming a steady state operating temperature of T=350K from the reference above that was I assumed and took half from melting point of aluminum metal which was 700K as mentioned in  (https://www.nss.org/settlement/nasa/spaceresvol2/thermalmanagement.html)

$$Qrad = 0.92 * 5.67*10^-8 * 0.48 *(350^4 - 3^4)$$

Qrad = 375W

Here this exceeds the generated heat load(Qgen= =150W) by a factor of nearly 2.5, which indicates the assumed temperature does not represent the true equilibrium state. At steady state, radiated heat must equal generated heat exactly(Qrad = Qgen), But above solution exceed it by nearly 2.5 times.

$$\frac{dE}{dt} = Q_gen - Q_rad = 0$$

Its the first law of thermodynamic applied to a system with no other heat paths. 

If Qrad not equal to Qgen, Then the system isnt at steady state. From above result its shows its cooling down Qrad>Qgen, Towards the point where they become equal.

#### Lets find out at what temperature does both temperature actually settles at ?

$$Qrad = $$\epsilon \sigma A(Trad^4 - Tspace^4)$$

$$\epsilon$$ = 0.92 , $$\sigma = 5.67*10^-8 W/m^2k^4$$ , $$A = 0.48m^2$$ , Tspace = 3k

At steady state , setting Qrad=Qgen=150W:

$$150 = 0.92 * 5.67*10^-8 * 0.48 * (T^4_rad - 3^4)$$

For finding $$T^4_rad$$

$$T^4_rad - 81 = \frac{150}{0.92 * 5.67*10^-8 * 0.48} = 5.99*10^9$$

$$T^4_rad = 5.99*10^9 + 81 = 5.99*10^9 K^4$$

Therefore, $$T_rad = (5.99*10^9)^\frac{1}{4}$$

$$T_rad = 278.19K$$

## Result :- This value represents the actual steady state operating temperature of the radiator under the given 150W heat load, and is approximately 72K lower than the initial design assumption of 350K.
